# 11.0 Virtualization, Cloud, and IoT — cheat sheet

## Virtual and software-defined

- Type 1 hypervisor sits on the hardware. Type 2 sits on an OS.
- Guests on the same vSwitch talk without the physical wire. A SPAN on the physical switch will not see it.
- Live migration keeps the MAC and IP. The destination must have the VLAN.
- SDN: the switch forwards, the controller decides. If the switches cannot survive a dead controller, the controller is a core device.
- SD-WAN picks MPLS, broadband, or LTE per application. The underlay can still fail. The overlay is tunnels.

## UC and web

- REST = HTTP and usually JSON. It uses 443. Allowing HTTPS allows the API.
- A video call is megabits. A voice call is tens of kilobits. Both hate jitter. Mark and queue on the WAN and on the AP.

## Storage

- NAS = files (SMB, NFS). SAN = disks.
- Fibre Channel = its own fabric, not IP. FCoE = FC in Ethernet, not routable, lossless. iSCSI = SCSI over TCP, 860 and 3260.
- Zone and mask LUNs. Multipath on two real fabrics. Jumbo frames must match end to end.

## Cloud

- IaaS you patch the OS. PaaS you bring the app. SaaS you bring the users. The provider does not configure your security group.
- Internet VPN is quick. A private circuit into the region is predictable. Do not overlap the VPC with the office.
- Elastic addresses change. Depend on a name or a load balancer.

## IoT

- Own VLAN, no default password, no default route unless it needs one.
- They are often never patched. Isolation is the compensation.
- A camera does not need the file server. Industrial controllers stay off the office LAN.

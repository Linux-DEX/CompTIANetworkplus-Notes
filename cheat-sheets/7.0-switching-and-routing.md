# 7.0 Switching and Routing — cheat sheet

## Switch

- Learns source MACs. Known unicast goes to one port. Unknown unicast and broadcasts flood the VLAN.
- Store-and-forward checks the FCS. Cut-through starts sending early and will forward damage.
- Shut unused ports. Do not leave users on VLAN 1. Save the config.

## STP

- Allows redundant links, blocks one so there is no loop. Root = lowest bridge ID. Set the priority yourself.
- Root port = best path to root. Designated = forwards for that segment. The other port blocks.
- Rapid STP (802.1w) converges in seconds. 802.1D can take 30–50.
- PortFast on PCs only. BPDU Guard shuts a PortFast port that hears a BPDU. Root Guard stops a rogue root.

## PoE

- af ≈ 15 W, at ≈ 30 W, bt ≈ 60 or 100 W, measured at the switch. The power supply's budget is the real limit.
- A non-PoE device on a PoE port is fine. A passive always-on injector is not.

## Routing

- Longest prefix wins. Then lower administrative distance. Then lower metric, inside one protocol.
- Connected 0, static 1, eBGP 20, OSPF 110, RIP 120. A floating static is a static with a worse distance, used as backup.
- Default = `0.0.0.0/0`. RIP counts hops (15 max). OSPF cost follows bandwidth. EIGRP uses bandwidth and delay.
- IGP = inside your network (OSPF, EIGRP, RIP, IS-IS). EGP = between networks (BGP). BGP loop check = your own AS in the path.
- Distance vector hears rumors. Link state builds the map. Split horizon and poison reverse limit RIP loops. TTL is the backstop.
- Two defaults pointed at each other loop. Traceroute shows the same hops repeating.

## VLAN and trunk

- Access port = one untagged VLAN. Trunk = 802.1Q tags, 4 extra bytes, frame up to 1522.
- Native VLAN is untagged and must match on both ends. Prefer an unused native VLAN.
- Turn off DTP. Allow only the VLANs the trunk needs.
- Router on a stick = one trunk, subinterfaces. A layer-3 switch does the same job in hardware.
- SOHO "DMZ" often means forward everything. Forward one port instead. Change the default LAN if you will VPN to an office using the same range.

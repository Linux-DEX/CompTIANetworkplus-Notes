# 5.0 IP and Core Protocols — cheat sheet

## 5.1 Convert an address

- IPv4 = 32 bits = 4 octets, 0–255. Places: **128 64 32 16 8 4 2 1**.
- Mask 1s = network, 0s = host. `/24` = `255.255.255.0`.
- Network = host bits all 0. Broadcast = host bits all 1. Usable = everything between. Count = 2^(host bits) − 2.
- Block size of the interesting octet = 256 − mask octet. /26 mask 192, block 64, 62 hosts.
- `192.168.1.10/24` → network .0, first .1, last .254, broadcast .255.
- `192.168.1.10/26` → network .0, broadcast .63. `192.168.1.70/26` is a different network (.64).
- Classes, legacy: A 1–126 /8, B 128–191 /16, C 192–223 /24, D 224–239 multicast, E reserved. 127 is loopback.
- Private: `10/8`, `172.16/12` (only through 172.31), `192.168/16`.
- Special: `127.0.0.1` me. `169.254/16` DHCP failed. `255.255.255.255` local broadcast, not routed. `0.0.0.0` this host or the default route.
- A mask is contiguous 1s then 0s. `255.255.0.255` is not a mask.
- IPv6 = 128 bits, hex, `::` once. `fe80::` link-local. No broadcast.

## 5.2 The protocols around IP

- IP: connectionless, best effort. TTL dies at 0. Protocol numbers: ICMP 1, IGMP 2, TCP 6, UDP 17, GRE 47.
- UDP: 8 bytes, no handshake, no retry, one datagram in = one datagram out. DNS, DHCP, NTP, SNMP, voice.
- ARP: broadcast "who has this IPv4?", unicast reply with the MAC. Cache it. Off-subnet, ARP for the gateway, not the far host. Gratuitous ARP = unsolicited announcement (also how spoofing looks). RARP is dead; DHCP replaced it. IPv6 uses Neighbor Discovery instead.
- ICMP has types, not ports. Echo 8/0 = ping. Unreachable 3 (code 4 = need to fragment). Time exceeded 11 = traceroute. Dropping all ICMP breaks path MTU discovery.
- Traceroute: TTL 1, 2, 3… Windows uses ICMP. Unix often uses UDP.
- IGMP: host tells the router which multicast group it wants. Snooping switches listen and do not flood. `224.0.0.1` all hosts, `224.0.0.2` all routers. IGMP is the last hop; it is not the multicast routing protocol.

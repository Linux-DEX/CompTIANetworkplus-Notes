# 12.0 Network+ N10-009 — cheat sheet

The long versions are in `notes/12.0-n10-009/`. Sections 1.0–11.0 still hold the rest of the course.

## Architectures

- Access connects users. Distribution applies policy and routes between VLANs. Core moves traffic fast.
- Collapsed core merges core and distribution. Access stays separate.
- Spine-leaf: every leaf to every spine, spines not cabled to each other. Server-to-server is leaf-spine-leaf. ECMP, not a blocked STP link.
- North-south enters and leaves the data center. East-west is server to server inside it.
- Hub-and-spoke: spokes meet at the hub. Star is the LAN name for that shape. Point-to-point has two ends.

## Modern

- SD-WAN: application aware, transport agnostic, central policy, zero-touch. The underlay can still fail.
- VXLAN: Ethernet inside UDP 4789. VTEP encapsulates. VNI is 24 bits. VLAN IDs stop at 4094. DCI stretches a segment and also stretches the failure domain.
- Zero trust: authenticate and authorize the request. The VLAN is not the permission.
- SASE = WAN plus security at a cloud edge. SSE = the security half. Expansion is Service Edge.
- IaC: templates in source control. Drift is live config that no longer matches the file.
- IPv6: dual stack, tunnel, or NAT64 (DNS64 invents the AAAA, NAT64 rewrites the packet).

## Cloud

- Public is shared. Private is yours. Hybrid is both, connected.
- Scalability is planned growth. Elasticity grows and shrinks with load. Multitenancy means other customers share the hardware.
- NFV is a firewall or router as software. SDN is who decides the path.
- Security group: stateful, on the instance. NACL: stateless, on the subnet, both directions written out.
- Internet gateway is the front door. NAT gateway is outbound-only for a private subnet.
- CDN caches at the edge. The origin still needs a firewall.

## Recovery and operations

- RPO = how much data, in time. RTO = how long you may be down. MTTR = average repair. MTBF = average time between failures.
- Cold = empty room. Warm = hardware, stale data. Hot = running copy. Tabletop talks. Validation fails a real component.
- EOL = not sold. EOS = not patched. IPAM is the address database. Golden config is the approved file.
- In-band dies with the network. Out-of-band is console, a management path, or cellular. Jump box first, then the routers.
- DNSSEC signs. DoT is TCP 853. DoH is DNS inside 443. NTP is UDP 123. PTP is the tight LAN clock. NTS authenticates NTP.
- CRC = bad frame. Runt = too short. Giant = too long. Admin down = shut on purpose. Err-disable = a violation. Suspended = a bundle member that does not match.

## Install, wireless, hardening

- 1U = 1.75 in. Match port-side intake or exhaust to the aisle. UPS stores energy. PDU only distributes it.
- DAC / twinax is a short copper cable with SFP or QSFP ends, for inside the rack. MPO is 12 or 24 fibers in one connector.
- 2.4 GHz non-overlapping: 1, 6, 11. 802.11h = radar avoidance on 5 GHz. Band steering pushes capable clients off 2.4.
- WPS PINs are brute-forceable. Turn WPS off.
- Port security limits MACs. DHCP snooping limits offers to trusted ports. DAI checks ARP against those leases. RA Guard drops rogue IPv6 routers.
- SVI is the layer-3 address of a VLAN. Screened subnet is the DMZ. Captive portal is not encryption.

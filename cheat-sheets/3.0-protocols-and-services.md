# 3.0 Protocols and Services — cheat sheet

Port = a process. Socket = IP + port. ICMP has no port. Ping is ICMP type 8 / type 0.

Well-known 0–1023. Registered 1024–49151. Ephemeral 49152–65535. Server listens on a fixed port. Client uses an ephemeral one.

## Which mail port

- Outbound and server-to-server: SMTP 25. Users submitting mail: 587.
- One device, take the mail away: POP3 110.
- Many devices, leave it on the server: IMAP 143.
- Encrypted: 465, 993, 995, or STARTTLS.

## Easy traps

- FTP active = server calls back from port 20. Passive = client opens the data connection. SFTP is SSH (22), not FTP. FTPS is FTP plus TLS.
- TFTP has no login. Do not expose it.
- HTTP is stateless. Cookies fake a session. 8080 is an alternate, not a standard.
- SNMP v1/v2c community string = cleartext password. Use v3.
- Hiding a service on a non-default port is not authentication. Clients must be told the new number.

## 3.2 Sharing across operating systems

- NFS 2049 = Unix file mounts. Often also needs RPC 111.
- SSH 22 = encrypted shell. SCP/SFTP ride it. Telnet 23 = the cleartext one you replace.
- SMB 445 = Windows shares. 137–139 = legacy NetBIOS path. Samba speaks SMB on Unix.
- LDAP 389 = the directory. Active Directory uses it. DNS must resolve or logins fail.
- Zeroconf: no DHCP → 169.254.0.0/16 (APIPA, no gateway). Names via mDNS (5353). Discovery via DNS-SD (Bonjour/Avahi).

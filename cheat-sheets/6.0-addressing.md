# 6.0 Addressing — cheat sheet

## Subnetting

- Block = 2^(host bits). Usable = block − 2. Interesting octet: block = 256 − mask.
- /24 = 254 hosts, /25 = 126, /26 = 62, /27 = 30, /28 = 14, /30 = 2.
- Network = host bits 0. Broadcast = host bits 1. First and last of the block are not hosts.
- VLSM: largest subnet first, no overlap. Summarize only a power-of-two block that starts on its own boundary.
- `10.1.1.77/26` is in `10.1.1.64`, broadcast `.127`.

## Delivery

- Unicast = one. Broadcast = all on the LAN (IPv4 only). Multicast = a joined group. Anycast = same address, nearest host.
- Private: `10/8`, `172.16/12`, `192.168/16`. `100.64/10` is the carrier, not you. `169.254/16` means DHCP failed.

## IPv6

- 128 bits. One `::` only. `/64` on a LAN.
- Global `2000::/3`. Link-local `fe80::/10` on every interface. Unique local `fd00::/8`. Multicast `ff00::/8`. Loopback `::1`. No broadcast.
- SLAAC = host builds the address from the router advertisement. DHCPv6 = a server. NDP replaces ARP.
- Do not filter all ICMPv6. Path MTU and neighbor discovery need it.

## Assignment

- DHCP = DORA. UDP 67 server, 68 client. Renew at 50%. Relay (ip helper) when the server is off-subnet.
- Reservation = DHCP always gives this MAC that address. Static = configured on the host. Keep statics out of the pool.
- 169.254 = no DHCP, no gateway.

## DNS

- UDP/53, TCP/53 for transfers and big answers. Recursive = the PC's question. Iterative = the resolver walking root, TLD, authoritative.
- A, AAAA, CNAME, MX (low number first), NS, PTR, TXT, SRV, SOA (serial).
- Lower TTL before you change a record. Split horizon = different answer inside and outside.

## Proxy and NAT

- Forward proxy = clients send web there. Reverse = in front of servers. Transparent = intercepts without config.
- Static NAT = one to one. Dynamic = a pool. PAT = many hosts, one public address, distinguished by port. PAT is what home routers do.
- Inside local = private host. Inside global = that host as the Internet sees it.
- Do not NAT traffic that should enter a VPN. NAT breaks protocols that hide an address in the payload.

## Tools

- Address wrong: `ip` / `ipconfig`. Path: ping gateway, then far IP, then a name. Names: `dig`. Path of hops: traceroute. Who owns the MAC: `arp`. What is listening: `ss` / `netstat`.
- Ping failing does not prove the host is down. ICMP may be filtered.

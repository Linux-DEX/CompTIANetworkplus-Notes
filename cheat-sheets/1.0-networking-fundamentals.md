# 1.0 Networking Fundamentals — cheat sheet

Short form of `notes/1.0-networking-fundamentals/`. One line each. Open the numbered note when you need the why.

## 1.1 Terms

- Network = devices + media + adapters + rules (NOS).
- Endpoint node = where data starts or stops. Redistribution node = switch, router, hub.
- Server shares a service. Client asks. Peer does both. Terminal only displays; no local processing.
- Backbone carries most traffic. Serial = one cable. Hierarchical = a tree. Collapsed = one core. Parallel = collapsed with extra links for redundancy.

## 1.2 Size and models

- PAN person, LAN building, CAN campus, MAN city, WAN between sites, GAN worldwide, EN one company's LAN+WAN.
- LAN is the fast one. WAN joins LANs and is usually slower and carrier-owned.
- Internet = public TCP/IP. Intranet = private, same protocols. Extranet = a slice opened to named partners.
- Segment = a portion divided off by a switch or router.
- Centralized = one mainframe, dumb terminals, one failure kills it.
- Client/server = shared services, clients still compute locally.
- P2P = no dedicated server. Mixed = more than one model.

## 1.3 Topology

- Physical = the cables. Logical = the path data takes. A hub is a physical star and a logical bus.
- Unicast = one. Multicast = a group. Broadcast = everyone in the broadcast domain.
- Bus: one cable, 50 Ω terminator, one break kills the segment.
- Star: one cable per node to a hub (repeats to all) or a switch (forwards by MAC).
- Ring: upstream + downstream, token, one break kills a single ring.
- Tree: root and branches, at least three levels. Mesh: multiple paths. Full mesh links = n(n−1)/2.
- Hybrid: star-bus, star of stars, star-ring.

## 1.4 Media

- Bounded = copper or fiber. UTP = no shield, cheap. STP = foil/braid, must be grounded.
- Cat3 10 Mb. Cat5 100 Mb. Cat5e 1 Gb. Cat6 1 Gb to 100 m, 10 Gb to ~55 m. Cat6a 10 Gb to 100 m. Cat8 25/40 Gb to 30 m.
- Coax: RG-58/RG-8 are 50 Ω Ethernet. RG-59/RG-6 are 75 Ω video and cable.
- SMF ~9 μm, laser, kilometers. MMF 50/62.5 μm, LED/VCSEL, hundreds of meters. Graded-index limits modal dispersion.
- Fiber connectors: ST bayonet, SC square, LC small (SFPs), MTRJ duplex.
- 568 pieces: entrance/demarc, backbone, equipment room (MDF), closet (IDF), horizontal (90 m), work area.
- Plenum (CMP) = air-handling space. Riser (CMR) = between floors. PVC = neither; toxic smoke.

## 1.5 Pinouts

- 8P8C is the plug people call RJ-45. T568A and T568B swap orange and green.
- T568A pins: white/green, green, white/orange, blue, white/blue, orange, white/brown, brown. T568B swaps the orange and green pairs: white/orange, orange, white/green, blue, white/blue, green, white/brown, brown.
- Straight = same both ends = unlike devices (PC to switch). Crossover = A one end, B the other = like devices.
- 10/100: NIC transmits on 1–2, receives on 3–6. Switch port is the opposite (MDI-X). Gigabit uses all four pairs.
- Auto-MDI-X makes the crossover for you. It does not fix a split pair.
- Rollover = pin 1 to pin 8. Console only. Not Ethernet.

## 1.6 Connectors and modules

- DE-9 (DB-9) = RS-232 console. F-connector = 75 Ω TV coax. 66-block = voice. 110-block = data.
- GBIC 1G large → SFP 1G → SFP+ 10G → QSFP+ 40G → QSFP28 100G.
- FCoE = Fibre Channel inside Ethernet, not routable. iSCSI = SCSI over TCP, routable, ports 860/3260. InfiniBand = HPC fabric, not Ethernet.

## 1.7 Wireless media

- DSSS spreads with a code (802.11b). FHSS hops (Bluetooth). OFDM = many subcarriers (modern Wi-Fi).
- Infrared: line of sight, no walls. Bluetooth 2.4 GHz, class 2 ≈ 10 m. Microwave WAN: line of sight, kilometers.
- SSID ≤ 32 characters. Hiding it is not security.
- AP bridges wireless to wired. A home "router" is AP + router + switch.

## 1.8 Devices

- Hub L1, one collision domain. Switch L2, one collision domain per port, forwards by MAC. Router L3, one broadcast domain per port, forwards by IP.
- Gateway translates dissimilar protocols. Default gateway = the router address hosts use.
- Managed switch: mirror (SPAN), LACP aggregation, VLANs, PoE.
- IaaS you manage the OS. PaaS you manage the app. SaaS you manage data and users. NaaS you rent the network.
- Noise: ground a shield at one point, keep the twist, match impedance, terminate bus ends.
- Differential signaling: opposite voltages, receiver subtracts, common-mode noise cancels.

## 1.9 Advanced boxes

- Multilayer switch = L2 forward and L3 route in hardware.
- WLC configures lightweight APs. Intra-controller roam = same WLC. Inter = different WLCs.
- Load balancer: clients hit a VIP, balancer picks a real server.
- IDS = copy of the traffic, can only alert. IPS = inline, can drop.
- AAA: who are you, what may you do, what did you do.
- RADIUS UDP 1812/1813, password field only encrypted. TACACS+ TCP 49, whole body, device admin. Kerberos 88, tickets.
- UTM = many security features, one box, one failure point. NGFW = firewall plus application ID and DPI.
- IP PBX = phones on the LAN. Voice gateway reaches the PSTN. Content filter blocks destinations or file types.

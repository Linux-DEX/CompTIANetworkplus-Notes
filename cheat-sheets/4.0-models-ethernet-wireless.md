# 4.0 Models, Ethernet, and Wireless — cheat sheet

## 4.1 OSI

Please Do Not Throw Sausage Pizza Away. Bottom = physical.

| L | Name | PDU | Remember |
|---|---|---|---|
| 7 | Application | Data | HTTP, DNS, SMTP. Not "Chrome" |
| 6 | Presentation | Data | Format, compression, TLS |
| 5 | Session | Data | Start and end the conversation |
| 4 | Transport | Segment / datagram | Ports. TCP or UDP. End to end |
| 3 | Network | Packet | IP. Routers. TTL |
| 2 | Data link | Frame | MAC. Switches. FCS. LLC + MAC sublayers |
| 1 | Physical | Bit | Cable, light, hub, repeater |

Encapsulation going out: data, segment, packet, frame, bits. A switch reads the frame. A router strips it and builds a new one. MAC = 48 bits, first 24 = vendor OUI.

## 4.2 TCP (the one to drill)

- IP protocol 6. Connection, reliable, ordered, byte stream. UDP is none of those.
- Header ≥ 20 bytes. Ports, sequence (bytes, not packets), ACK number = next byte wanted, flags, window, checksum.
- Flags: SYN open, ACK valid, FIN "I am done sending", RST abort, PSH deliver now, URG rare.
- Handshake: SYN (seq x) → SYN-ACK (seq y, ack x+1) → ACK (ack y+1). SYN and FIN each consume one sequence number.
- Close: FIN, ACK, FIN, ACK. Closer sits in TIME-WAIT for 2×MSL. CLOSE-WAIT stuck = the app never closed.
- Flow control = receiver window. Zero window = receiver buffer full.
- Congestion = sender cwnd. Slow start doubles. Avoidance adds one MSS per RTT. 3 duplicate ACKs = fast retransmit, cut cwnd in half. Timeout = back to slow start.
- MSS ≈ MTU − 40. Ethernet MTU 1500, MSS 1460. DF bit + ICMP "fragmentation needed" = path MTU discovery. Filtering that ICMP hangs large transfers.
- Socket = source IP, source port, dest IP, dest port.
- Half-open = SYN-RECEIVED, waiting for the last ACK. Many of them = SYN flood or packet loss.
- TCP/IP layers by name: application, transport, internet, link. Use names. OSI numbers and TCP/IP numbers are not the same stack.

UDP: 8-byte header, protocol 17, no state, keeps message boundaries. DNS, DHCP, NTP, SNMP, voice.

## 4.3 Ethernet names

`speed + BASE + medium`. BASE = baseband.

- 10BASE5 thick coax, 500 m, RG-8, 50 Ω. 10BASE2 thin coax, 185 m, RG-58.
- 10BASE-T and 100BASE-TX: two pairs, 100 m. 100BASE-FX: multimode, ~400 m half / 2 km full.
- 1000BASE-T: four pairs, Cat5e, 100 m. SX = MM 850 nm. LX = 1310 nm, ~5 km SM.
- 10GBASE-T Cat6a 100 m. SR short MM. LR 10 km SM. ER 40 km SM. A trailing W = SONET WAN PHY.
- Auto on one end, 100/full hardcoded on the other → the auto end falls back to half duplex. Late collisions.
- Frame payload 46–1500. FCS failure = drop at layer 2. 802.1Q tag makes it 1522.

## 4.4 Wi-Fi

- BSS = one AP. ESS = several APs, one SSID, roaming. IBSS = ad hoc, no AP. BSSID = the AP's radio MAC.
- CSMA/CA. 2.4 GHz non-overlapping channels: 1, 6, 11.
- a = 5 GHz 54 Mb. b = 2.4 GHz 11 Mb. g = 2.4 GHz 54 Mb and talks to b. n/Wi-Fi 4 = both bands, MIMO. ac/Wi-Fi 5 = 5 GHz. ax/Wi-Fi 6 = OFDMA, 6E adds 6 GHz.
- 150 Mb is one 802.11n stream, not the top of n.
- Beacon ≈ every 100 ms, carries the SSID. Hiding the SSID does not hide the network.
- Omnidirectional = doughnut, ceiling center. Directional = a beam. Gain steals power from other directions; it does not create it.
- Order: survey, then mount, then change the default password, then WPA2/WPA3. Association first, DHCP after.

## 4.5 Segmentation

- Physical = different boxes. Logical = VLANs on one box. A VLAN stops broadcasts. An ACL or firewall stops packets.
- Reasons: security, unpatchable legacy hosts, smaller broadcast domains, PCI scope, DMZ for public servers, a lab that is allowed to break, SCADA/ICS off the office LAN.
- PCI segmentation is not required. It shrinks what the assessor must review.
- DMZ: Internet reaches the public servers; those servers do not initiate into the internal network.
- Honeypot = one decoy. Honeynet = a decoy segment. It must not route into production.

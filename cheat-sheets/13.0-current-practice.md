# 13.0 Current practice — cheat sheet

Past the N10-009 set in 12.0. The long versions are in `notes/13.0-current-practice/`.

## QUIC, HTTP/3, MACsec

- QUIC is UDP 443 with TLS 1.3 built in. One lost packet stalls one stream. The connection ID survives an IP change.
- HTTP/3 is HTTP on QUIC. HTTP/2 is HTTP on TCP. Blocking UDP 443 forces a fallback.
- MACsec (802.1AE) encrypts one Ethernet hop. MAC addresses stay visible. The next hop can read the frame. MKA agrees the keys.

## EVPN, BFD, microsegmentation

- EVPN is BGP for VXLAN. Type 2 is a MAC/IP. Type 5 is a prefix. ARP suppression answers locally. Anycast gateway is the same gateway IP on every leaf.
- BFD is a fast hello beside the routing protocol. Three misses and the route drops. Too aggressive on a lossy link, and it flaps.
- Microsegmentation is a policy inside one subnet. Learn the flows, then default-deny.

## Automation, RPKI, ZTNA

- YANG is the schema. NETCONF is XML over SSH port 830, with a candidate config. RESTCONF is the same tree over HTTPS.
- Streaming telemetry pushes YANG-modeled counters. SNMP waits to be polled. gNMI is the usual subscription.
- A ROA says which AS may originate a prefix. Valid, Invalid, or NotFound. Invalid is a hijack signal. RPKI checks the origin.
- ZTNA opens one application after identity and posture. A VPN opens a network.

## Wireless, IoT, OT

- OWE (Enhanced Open) encrypts an open SSID and does not prove which AP you joined.
- TWT is the Wi-Fi 6 sleep schedule. A sleeping sensor looks associated and stays quiet.
- A 5G slice is a virtual network across radio and core: eMBB for capacity, URLLC for latency, mMTC for huge numbers of small devices.
- MQTT is pub/sub to a broker. 1883, or 8883 with TLS. QoS 0, 1, or 2.
- CoAP is a small UDP HTTP. 5683, or 5684 with DTLS.
- Purdue: levels 0–2 are the process and its controllers, 3 is site operations, 3.5 is the only DMZ, 4–5 are business IT. Do not route the office straight to a PLC.

# 6.1 Subnetting

Section **6.0 Addressing**. Binary and masks are in 5.1. This note is how you cut one network into many.

## Why subnet

A single LAN is one broadcast domain. Every ARP, every DHCP discover, and every misbehaving host hits every other host. Subnetting borrows **host bits** and turns them into **network bits**, so one address block becomes several smaller networks. Routers (or layer-3 switches) sit between them. Broadcasts stop at the boundary. You also stop handing a /16 to a closet that has 20 PCs.

## The only arithmetic

```text
block size = 2^(host bits)
usable hosts = block size − 2
```

The −2 is the network address (host bits all 0) and the broadcast (host bits all 1).

The **interesting octet** is the one where the mask is not 0 and not 255. Its block size is `256 − mask-value`.

| Prefix | Mask ending | Block | Usable |
|---|---|---|---|
| /24 | 0 | 256 | 254 |
| /25 | 128 | 128 | 126 |
| /26 | 192 | 64 | 62 |
| /27 | 224 | 32 | 30 |
| /28 | 240 | 16 | 14 |
| /29 | 248 | 8 | 6 |
| /30 | 252 | 4 | 2 |
| /31 | 254 | 2 | 2, point-to-point only (RFC 3021) |
| /32 | 255 | 1 | a single host route |

Memorize /24, /26, /27, /28, /30. The others fall out of the same table.

## One worked /26

Address `10.1.1.77`, mask `255.255.255.192`.

Block size in the last octet is 64. Networks land on 0, 64, 128, 192.

77 sits between 64 and 128, so:

| | Address |
|---|---|
| Network | 10.1.1.64 |
| First host | 10.1.1.65 |
| Last host | 10.1.1.126 |
| Broadcast | 10.1.1.127 |
| Next network | 10.1.1.128 |

`10.1.1.77` and `10.1.1.50` are **not** on the same subnet, even though both start with 10.1.1. They need a router.

## A /27, so the boundary is not on a round number

`192.168.5.100/27`. Block is 32. Multiples of 32: 0, 32, 64, 96, 128.

100 is in the block that starts at 96.

| Network | 192.168.5.96 |
| First host | 192.168.5.97 |
| Last host | 192.168.5.126 |
| Broadcast | 192.168.5.127 |

## Borrowing from a larger octet

`172.16.40.10/20`. A /20 means the mask is `255.255.240.0`. The interesting octet is the **third**. `256 − 240 = 16`, so third-octet blocks are 0, 16, 32, 48.

40 is in the block that starts at 32.

| Network | 172.16.32.0 |
| First host | 172.16.32.1 |
| Last host | 172.16.47.254 |
| Broadcast | 172.16.47.255 |

Host bits run through the rest of the third octet **and** the entire fourth. The broadcast is not `172.16.32.255`.

## How many subnets and hosts

Start from a classful or assigned block and borrow.

Example: `192.168.1.0/24`, and you need subnets of at least 20 hosts.

20 hosts needs 5 host bits (2^5 − 2 = 30). That leaves 8 − 5 = 3 subnet bits, so 2^3 = 8 subnets, each /27, each with 30 usable addresses.

If the question says "at least 20 hosts **and** as many subnets as possible", still use 5 host bits. If it says "at least 8 subnets and as many hosts as possible", use 3 subnet bits and leave 5 for hosts. Same split, different sentence.

## VLSM

Variable-length subnet masking means the subnets are **not** the same size. You size each one to what it holds, largest first, so you do not strand a block in the middle of a bigger one you still need.

`10.10.10.0/24` must cover:

| Need | Smallest prefix | Block |
|---|---|---|
| 100 hosts | /25 | 128 addresses |
| 50 hosts | /26 | 64 |
| 20 hosts | /27 | 32 |
| 2 routers on a link | /30 | 4 |

Lay them down in that order, no overlap:

| Subnet | Range |
|---|---|
| /25 | 10.10.10.0 – 10.10.10.127 |
| /26 | 10.10.10.128 – 10.10.10.191 |
| /27 | 10.10.10.192 – 10.10.10.223 |
| /30 | 10.10.10.224 – 10.10.10.227 |

What remains, from .228 up, is free. Assigning the /30 first at .0 would have split the space the /25 needed.

## Summarization

The reverse of subnetting. Several contiguous networks collapse into one route if they share a prefix and fill a power-of-two block.

`10.1.0.0/24`, `10.1.1.0/24`, `10.1.2.0/24`, `10.1.3.0/24` are four consecutive /24s starting on a boundary of 4. Together they are `10.1.0.0/22` (mask 255.255.252.0, block of 4 in the third octet).

You cannot summarize `10.1.1.0/24` and `10.1.2.0/24` alone into a /23. A /23 block is 2 long and must start on an even boundary (0, 2, 4). `.1` and `.2` straddle two different /23s.

## Checks

- Network address: host bits are 0. If your "network" is odd in the interesting octet, it is probably a host.
- Two hosts communicate without a router only when network number **and** mask match.
- A /30 has two usable addresses. That is a router-to-router link, not a LAN.
- The first and last address of a block are not hosts, except on a /31 or /32.

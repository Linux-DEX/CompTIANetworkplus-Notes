# 6.3 IPv6

Section **6.0 Addressing**.

IPv4's 32 bits ran out. IPv6 uses **128 bits**, written as eight groups of four hexadecimal digits.

```text
2001:0db8:0000:0000:0000:0000:0000:0001
```

## Compression

- Drop leading zeros in a group: `0db8` is `db8`.
- Replace **one** run of all-zero groups with `::`. Only one `::` is allowed, or the address is ambiguous.

```text
2001:db8::1
```

`fe80:0000:0000:0000:0000:0000:0000:0001` is `fe80::1`.

A prefix is written the same way as IPv4 CIDR: `2001:db8:1::/64`. The first 64 bits are the network. The last 64 are the interface identifier on almost every LAN. You do not usually subnet inside the host half.

## Address types

| Type | Prefix | What it is |
|---|---|---|
| Global unicast | `2000::/3` | The public Internet address. `2001:db8::/32` is the documentation range, like 192.0.2.0/24 |
| Link-local | `fe80::/10` | Required on every interface. Used for on-link traffic and for routing protocols. Not routed |
| Unique local | `fc00::/7`, in practice `fd00::/8` | Private, like RFC 1918. Not routed on the Internet |
| Multicast | `ff00::/8` | Replaces broadcast. `ff02::1` is all nodes on the link. `ff02::2` is all routers |
| Anycast | A unicast address assigned to several nodes | Routing delivers to the nearest |
| Unspecified | `::` | "No address yet", the source during autoconfiguration |
| Loopback | `::1` | This host |

There is no broadcast address. Anything that used to be a broadcast (ARP, "who has this") is multicast, via Neighbor Discovery.

## How a host gets an address

**Static.** You type the address and the gateway. Used on routers and on servers that must not move.

**SLAAC (stateless address autoconfiguration).** The router sends a Router Advertisement with the prefix. The host builds the interface id itself:

- EUI-64: take the MAC, insert `fffe` in the middle, flip the universal/local bit.
- Privacy extensions: a random interface id that changes, so a laptop is not trackable by its address. This is the default on most clients now.

**DHCPv6.** Stateful, like IPv4 DHCP, when you want a server to record who received which address. It can also be used only for options (DNS servers) while the address still comes from SLAAC. Router Advertisements carry flags that say which combination is in use.

**Link-local** is generated on every interface even when nothing else works. Two hosts on the same LAN can talk using link-local addresses with no router and no DHCPv6. You must name the interface on some operating systems (`fe80::1%eth0`) because `fe80::/10` exists on every link.

## Neighbor Discovery

ICMPv6 replaces ARP and adds router discovery.

| Message | Job |
|---|---|
| Router Solicitation / Advertisement | Hosts learn the prefix, the default router, and whether to use DHCPv6 |
| Neighbor Solicitation / Advertisement | "Who has this IPv6 address?" and the answer. Also used for duplicate-address detection |
| Redirect | A router points the host at a better next hop on the same link |

Duplicate-address detection runs before a host uses an address. It sends a Neighbor Solicitation for its own candidate. A reply means someone else has it.

## Header differences that matter

- No checksum in the IPv6 header. Links and TCP/UDP already check.
- No fragmentation by routers. The source fragments, or path MTU discovery (ICMPv6 "packet too big") shrinks the packet. Filtering all ICMPv6 breaks this.
- Next Header replaces the protocol number.
- Hop Limit replaces TTL.
- Extension headers (routing, fragmentation, ESP) chain off the main header instead of options crammed into it.

## Dual stack and tunneling

Most networks run **dual stack**: every interface has IPv4 and IPv6, and DNS answers with both an A and an AAAA. The host tries one, often IPv6 first (Happy Eyeballs falls back quickly if v6 is broken).

Tunneling (6in4, Teredo, ISATAP) carries IPv6 inside IPv4 where the path is v4-only. It is a transition tool. A native prefix from the provider is the design you want.

## What breaks in practice

- A firewall that drops ICMPv6. Neighbor Discovery and path MTU both need it.
- SLAAC with no DNS. The host has an address and no resolver, unless RDNSS is in the Router Advertisement or DHCPv6 is providing it.
- Forgetting that link-local is not a global address. It will not cross a router.
- Typing more than one `::`.

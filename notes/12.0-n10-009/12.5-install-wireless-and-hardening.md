# 12.5 Installation, Wireless Details, and Hardening

Section **12.0 Network+ N10-009**. Closets and plenum rules are in 1.4. 802.11 standards are in 4.4. Wireless ciphers are in 10.4. This note fills the installation factors, the radio details, and the switch features the current exam lists beside those chapters.

## The room and the rack

**MDF** is the building's main frame. **IDF** is a closet between the MDF and the users (1.4). Both want a lock, a patch field, and cooling. A closet that is also a storage room will lose the switch to a box of paper on the intake.

| Item | What matters |
|---|---|
| Rack | 19-inch equipment width. Height is in rack units. **1U is 1.75 inches**. Leave space to pull a power supply and to dress cable so it does not block the fans |
| Airflow | **Port-side intake** or **port-side exhaust** is printed on the switch. Cold air enters the cold aisle. Hot air leaves into the hot aisle. A switch installed backwards heats its neighbor's intake |
| Lock | The cabinet locks. The room locks. A console port in an open hallway is a keyboard |
| Patch panel | Copper horizontal cable lands here (1.6). You move patch cords, not the permanent run |
| Fiber distribution panel | Backbone strands land here and are patched with jumpers. Mind the bend radius |

## Power and the air

| Piece | Job |
|---|---|
| UPS | Batteries. Minutes of runtime, long enough to ride through a blip or to shut down cleanly. Test it under load (9.3) |
| PDU | Distributes the circuit to the outlets in the rack. A metered PDU shows the draw. It does not store energy. A PDU is not a UPS |
| Load | Add the nameplate draw. A continuous load wants headroom under the breaker, commonly about 80 percent. A full rack on one 15 A circuit is how a breaker opens at the worst minute |
| Voltage | The power supply must match the feed (120 V versus 208/240 V). The cord is not a converter |
| Generator | What the UPS bridges to, if the site has one. The UPS is the gap. The generator is the hours |

| Environment | Failure when it is wrong |
|---|---|
| Temperature | Switches throttle or die. A closet with no return path for air cooks the top of the rack |
| Humidity | Too low invites static. Too high invites condensation and corrosion. The device's spec is a range, not "a room" |
| Fire suppression | A clean agent, or a pre-action system, in a room full of live gear. Do not store cable under a sprinkler head you have blocked. Water on a running rack is the last option the building has |

## Short copper and multi-fiber

**Direct attach copper (DAC)**, often **twinaxial**, is a fixed-length copper cable with the SFP or QSFP already on each end. It links devices in the same rack or the next rack, typically a few meters. It is cheap and it uses little power. It is the wrong tool for a run down the hall. Fiber or a horizontal copper category cable is that tool (1.4).

**MPO** (multi-fiber push-on) puts 12 or 24 fibers in one connector. 40 and 100 Gigabit Ethernet use it, and a breakout cable can split it to duplex **LC**. Polarity (which fiber is TX on the far end) is the thing that makes a new MPO link stay dark. The duplex fiber connectors you already know — ST, SC, LC — are in 1.4.

## Wireless details that sit beside 4.4

| Topic | The fact |
|---|---|
| Channel width | 20 MHz is the basic channel. 40, 80, 160, and (Wi-Fi 7) 320 MHz carry more and overlap their neighbors sooner. Wide channels belong where the band is empty |
| Non-overlapping | 2.4 GHz: channels **1, 6, and 11**. 5 and 6 GHz have many more |
| 802.11h | **DFS** and transmit power control on 5 GHz, so Wi-Fi can share the band with radar. An AP that hears radar must leave the channel. A client that only fails on some 5 GHz channels is often this |
| Regulatory domain | The country code on the AP decides which channels are legal. The wrong country is both a poor channel plan and a compliance problem |
| Band steering | The AP nudges a dual-band client onto 5 or 6 GHz, so 2.4 GHz remains for devices that have no other band |
| ESSID | The SSID shared by every AP in an ESS. The **BSSID** is still one AP's radio MAC (4.4) |
| Autonomous AP | The config lives on the AP. Fine for a handful of radios |
| Lightweight AP | The config lives on the wireless controller (1.9). The AP forwards frames |
| Mesh | APs use wireless as their backhaul. You spend airtime twice. Use it where a cable cannot go |
| Point-to-point | A directional link between two radios (a bridge), not an AP serving a floor |
| Infrastructure | Clients associate to an AP. This is the normal office |
| Ad hoc | Clients talk with no AP (IBSS, 4.4) |
| Captive portal | A web page the client must pass before the firewall allows the Internet. It is not encryption. Pair it with a guest VLAN |
| PSK versus Enterprise | One passphrase (Personal) versus 802.1X and per-user credentials (Enterprise, 10.4) |

**WPS** (Wi-Fi Protected Setup) joins a client with a PIN or a button. The PIN is brute-forceable. Turn WPS off. A sticker with the PIN on the router is the same as an open network that takes an afternoon.

## Switch and identity controls

| Control | What it stops |
|---|---|
| Port security | A desk port accepts a limited number of MAC addresses. **Sticky** learning writes the first MACs into the config. A violation can shut the port (error-disabled, 12.4) |
| 802.1X | No user traffic until RADIUS says yes. **EAPoL** is the EAP frame on the wire during that exchange (10.1) |
| MAC filtering | An allow-list of MACs. Anyone who can hear a permitted MAC can use it. Better than an open port, weaker than 802.1X (10.4) |
| DHCP snooping | DHCP offers are accepted only on trusted ports (the server's port). A rogue server on a desk port is ignored (10.3) |
| Dynamic ARP inspection | Uses the snooping table to drop ARP replies that do not match the DHCP lease. This is the local fix for ARP spoofing |
| RA Guard | Drops rogue IPv6 Router Advertisements from access ports, so a laptop cannot become the subnet's gateway |

An **SVI** (switch virtual interface) is the layer-3 interface for a VLAN. VLAN 10's SVI at `10.0.0.1` is the gateway for that VLAN on a multilayer switch. Shutting the VLAN shuts the SVI. A VLAN with no SVI and no router is a broadcast domain with no way out.

## Security terms the older chapters only touch

| Term | Meaning |
|---|---|
| Data in transit | Protected on the wire: TLS, IPSec, WPA |
| Data at rest | Protected on the disk: full-disk encryption. A stolen laptop without it is a data breach that already happened |
| PKI certificate | Signed by a certificate authority other people already trust (10.2) |
| Self-signed certificate | Signed by the same host that presents it. Fine for a lab. A browser warning in production |
| TOTP | A code that changes every 30 seconds. A second factor (something you have). Clock skew makes every code wrong |
| SAML | An assertion that carries single sign-on between an identity provider and an application (10.1) |
| Geofencing | A policy tied to place: a login allowed from the countries you operate in, or a resource offered only inside a site. A VPN from somewhere else is the bypass you have to decide about |
| Data locality | The rule, often legal, about which country the data may sit in. A replica in another region can break it |
| GDPR | The EU rule set for personal data. It is why locality and retention show up in a network design |
| PCI DSS | Cardholder data. Segmentation shrinks the systems an assessor must review (4.5) |
| BYOD | A personal device on the corporate network. Put it through NAC, on its own VLAN, and assume you do not control its patches |
| DLP | Data loss prevention. Watches for sensitive data leaving by mail, upload, or USB |
| URL filtering | Blocks by the address of the site |
| Content filtering | Blocks by category or by what is inside the transfer (1.9) |
| Screened subnet | The current name for a DMZ. Internet-facing servers live here, and they do not start connections inward (4.5) |
| Trusted versus untrusted | Inside versus the Internet, as firewall zones. A guest VLAN is a third zone, not "trusted because it is in the building" |
| RFID | A badge or a tag. Physical access, not a Wi-Fi standard |
| Key management | Where keys are stored, who can export them, and how you rotate one that leaked (10.2) |

Zones, encryption, and 802.1X do different jobs. A screened subnet with no patching is a well-labeled compromise. A strong cipher with a shared WPA2 passphrase is a well-encrypted network that an evil twin can join.

# 12.4 Recovery, Name Security, and Management

Section **12.0 Network+ N10-009**. The troubleshooting order is 9.2. High availability hardware is 9.3. DNS records are 6.5. This note is the operational objectives those chapters do not spell out.

## Disaster recovery numbers

Say the number and the unit. A slogan ("we back up nightly") is not a metric.

| Metric | Question it answers | A useful value looks like |
|---|---|---|
| RPO — recovery point objective | How much data may be lost, measured as time | "15 minutes" means backups or replication at least that often. A nightly backup is a 24-hour RPO |
| RTO — recovery time objective | How long the service may stay down | "4 hours" is the clock from the declaration to users working again |
| MTTR — mean time to repair | How long a failed part actually takes to fix, on average | Includes finding the part, not only swapping it |
| MTBF — mean time between failures | How long a component runs before it fails, on average | Higher is quieter. It is a reliability figure, not a promise about your next outage |

RPO is data. RTO is the clock on the wall. A design can have a tight RPO (replication) and a terrible RTO (nobody has ever failed over). MTBF predicts how often you will use the RTO.

## Sites and tests

| Site | What is already there | Time to be useful |
|---|---|---|
| Cold | Space, power, maybe racks. No current data | Days. You ship hardware and restore |
| Warm | Hardware in place. Data is hours or a day behind | Hours. You restore or catch up replication, then cut over |
| Hot | A running copy, data nearly current | Minutes. You move traffic (DNS, a VIP, a routing change) |

**Active-active** serves on both sides at once. **Active-passive** keeps the second idle until failover (9.3). A **VIP** is the address clients use: an FHRP gateway address, or a load-balancer address. Clients keep the VIP. The box behind it can change.

| Test | What you learn |
|---|---|
| Tabletop | People walk the plan out loud. You find the missing phone number and the step nobody owns. You do not find a dead replica |
| Validation | You restore a backup, or you fail a link, on purpose. This is the only test that shows the RTO is real |

An untested hot site is a warm site with a higher bill.

## Life cycle and the golden file

| Term | Meaning |
|---|---|
| EOL — end of life | The vendor stops selling it |
| EOS — end of support | The vendor stops patching it. An EOS firewall is a risk you have accepted in writing, or it is a replacement project |
| Decommission | Wipe it, revoke its certificates, delete it from DNS, DHCP, and IPAM, and pull the cable. A powered-off server that still has a DNS name will be "fixed" by someone during an incident |
| Golden / baseline configuration | The approved config in the repository (12.2). Drift is a difference from that file |
| IPAM | The database of subnets, addresses, DHCP scopes, and names. A spreadsheet that three people edit is how you get a duplicate IP |
| SLA | The availability, latency, or response time a contract promises. Monitor the thing the SLA measures, or you will discover the miss when the provider does |
| Heat map | A wireless survey drawn as signal strength on the floor plan (4.4, 9.4) |

Diagrams the exam splits by layer:

| Diagram | Shows |
|---|---|
| Layer 1 | Cables, panels, ports, racks |
| Layer 2 | VLANs, trunks, STP roots, port channels |
| Layer 3 | Subnets, gateways, routing, NAT |

Asset inventory covers hardware, software, licenses, and warranty. A license that expired is an outage with an invoice.

## How you log in

| Method | When it is the right one |
|---|---|
| Console | The device has no network, or you are doing the first setup. A rollover or USB console cable (1.5). This path survives a bad route |
| SSH | Daily administration. Keys, not a shared password on a wiki |
| GUI | The same job, slower, and easy to click the wrong VLAN. HTTPS only |
| API | What automation and the controller use (12.2). Treat the token like a password |

**In-band** management rides the same network as the users. When that network is the outage, you cannot reach the box to fix it. **Out-of-band** is a separate path: a console server, a management VLAN that does not depend on the routing you just broke, or a cellular modem on the edge router.

A **jump box** (jump host) is a hardened host that admins reach first, usually by VPN and SSH. From there they reach routers and servers. Users do not SSH to the core. The jump box is logged, patched, and the only source your device ACLs allow.

**Clientless VPN** is a browser session to a portal, with no installed client. It fits web applications. A full tunnel client (8.3) is what you use when the user needs a drive mapping or a thick app. Split versus full tunnel is still the bandwidth and inspection choice in 8.3.

## DNS security

Records, zones, and the hierarchy are in 6.5. These are the protections around them.

| Control | What it actually does |
|---|---|
| DNSSEC | Signs the records. A validating resolver can reject a forged answer. The query is still visible. DNSSEC is integrity, not encryption |
| DoT — DNS over TLS | The lookup is encrypted on **TCP 853** |
| DoH — DNS over HTTPS | The lookup is encrypted on **TCP 443**, inside ordinary web traffic. Harder for a firewall to see, and harder to block without blocking the web |

**Authoritative** means this server holds the zone. **Non-authoritative** means the answer came from a cache. **Recursive** means the resolver walked the tree for the client (6.5). A public resolver (DoH to a host you do not run) will not know `files.corp.example`. Internal names stay on the internal resolver.

## Time, past NTP

NTP (UDP 123) is the clock most networks need (3.1). Two tighter or safer variants show up on the exam:

| Protocol | Use |
|---|---|
| PTP — Precision Time Protocol | Hardware timestamps, often on the local LAN, when milliseconds are too coarse: telecom, industrial, some finance. It is not a replacement you turn on "for accuracy" on a WAN and hope |
| NTS — Network Time Security | Authenticates NTP, so a stranger on the path cannot move your clocks. Kerberos, certificates, and logs all believe the clock |

## What the switch will say

Host commands (`ping`, `traceroute`, `dig`, `ipconfig`) are in 6.7. On the device itself:

| Command | You are looking for |
|---|---|
| `show mac-address-table` | Which port learned which MAC. A MAC on the wrong port is a move, a hub, or a loop |
| `show route` | The prefix, the next hop, the source (connected, static, OSPF). Longest prefix wins, then administrative distance (7.2) |
| `show interface` | Speed, duplex, and the counters below |
| `show config` | What is configured, including the mistake from last night |
| `show arp` | IP to MAC on this device |
| `show vlan` | Which ports are in which VLAN |
| `show power` | PoE budget used and remaining. A new AP that will not boot is often this number |

Interface counters and port state:

| Counter or state | Meaning |
|---|---|
| CRC | The frame failed its check. Cable, noise, a bad optic, or a duplex mismatch |
| Runts | Shorter than 64 bytes. Collisions or a bad NIC |
| Giants | Longer than the port's MTU. A tag the port did not expect, or a jumbo frame on a 1500-byte port |
| Drops | The device discarded the frame on purpose: a full buffer, or a policy |
| Administratively down | Someone shut the port. The cable is innocent |
| Down / down | No link. Cable, far end shut, or a dead optic. A wrong VLAN still shows link |
| Error-disabled | The switch shut the port after a violation: BPDU Guard, port security, a flapping link. Fix the cause, then re-enable. Clearing it with the cause still there shuts it again |
| Suspended | A member of a link aggregation whose settings do not match the bundle (VLAN, speed, mode). The other members may be fine |

LLDP and CDP (who is on the other end of this cable) are the discovery protocols in the tool list. Disable them on an edge that faces a network you do not trust (10.4).

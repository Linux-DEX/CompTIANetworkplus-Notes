# 10.1 Security Fundamentals and Access

Section **10.0 Security**.

## What you are protecting

**Confidentiality:** the data is not readable by the wrong party. Encryption and access control.

**Integrity:** the data was not changed, or you can tell that it was. Hashes, signatures, and logs that cannot be quietly edited.

**Availability:** the service is there when it is needed. Redundancy, backups, and the ability to absorb or shed load (10.3).

A control that improves one can hurt another. Encrypting everything makes inspection harder. A strict firewall that fails closed protects confidentiality and costs availability when you misconfigure it.

**Defense in depth** means one missed control is not the whole game: a stolen laptop still has disk encryption, the VPN still wants a second factor, the server VLAN still has an ACL. **Least privilege** means the account, the port, and the firewall rule allow the minimum that the job needs. **Separation of duties** means the person who can change a firewall is not the only person who can approve it.

## AAA

Authentication is who you are. Authorization is what you may do. Accounting is the record of what you did. The protocols (RADIUS, TACACS+, Kerberos) are in 1.9.

| Factor | Example |
|---|---|
| Something you know | A password or PIN |
| Something you have | A token, a phone, a smart card |
| Something you are | A fingerprint. Useful, and a bad sole factor because you cannot rotate a finger |
| Somewhere you are | Inside the office network, or in a country you operate in |

**Multi-factor** is two *different* factors. A password plus a second password is not multi-factor. A password plus a code from a token is.

**Single sign-on** means one authentication gets you a ticket (Kerberos, a SAML assertion) that other systems accept. Convenient, and the ticket becomes the thing worth stealing. Short lifetimes and the ability to revoke a session matter.

**802.1X** is port-based access on a switch or an AP. The port stays unauthorized until the client authenticates, usually with EAP, to a RADIUS server. A failed authentication lands on a guest VLAN or nowhere. This is the grown-up version of "the Wi-Fi password is on the wall".

## Network access controls

| Control | What it does |
|---|---|
| Firewall | Allows or denies by policy. Stateful firewalls track the connection, so return traffic is allowed without a second wide-open rule |
| ACL | The same idea on a router or a switch, usually stateless unless the platform says otherwise. Order matters. First match wins. An implicit deny sits at the bottom |
| NAC | Checks posture (patched, encrypted, not jailbroken) before the device is trusted, often together with 802.1X |
| Segmentation | Limits how far a compromised host can go (4.5) |
| IDS / IPS | IDS watches a copy and alerts. IPS sits inline and can drop. Placement and false positives are in 1.9 |
| Honeypot | A decoy, on its own segment, that must not be a path into the real network (4.5) |

## System tools, the ones that show up on the exam

| Tool | Job |
|---|---|
| Host firewall | Last filter, on the server, so a flat VLAN is not automatically full access |
| Anti-malware | Signatures and behavior on the endpoint. It does not see what never reaches the host |
| Patch management | The vulnerability is public. The race is whether you install the fix before it is used against you |
| File integrity | A hash of the important files, so a quiet edit is visible |
| Log collection | The host's own logs, shipped off the host, so an attacker who owns the box cannot be the only one holding the record |
| Configuration baseline | The build you meant. Drift from it is either a mistake or an incident |

Default accounts, default SNMP communities, and default Wi-Fi passwords are not theoretical. Changing them is the first hour of any install, not a later project.

## IDS and IPS, operationally

Put the IPS where it can see the traffic you care about and where a failure mode you have chosen (fail open or fail closed) is acceptable. Fail closed protects you and creates an outage when the box dies. Fail open preserves traffic and stops inspecting. Tune it. A sensor that pages you fifty times a night will be ignored the night it is right. Signatures age. A sensor that has not been updated is a record of last year's attacks.
